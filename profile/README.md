# OtterMind

OtterMind develops database software and infrastructure for AI applications. Our projects help developers query data, build application backends, and give agents long-term memory.

[Open OtterMind Studio](https://ottermind.ai/)

## Database tools

**[Chat2DB](https://github.com/OtterMind/Chat2DB)** is a local-first SQL workspace for developers, analysts, and database administrators. Connect to more than 40 database systems, write and run queries, and manage data in one cross-platform client.

**[Chat2DB-CLI](https://github.com/OtterMind/Chat2DB-CLI)** brings Chat2DB to the terminal. Manage data sources and run SQL from scripts, or give AI agents access to those operations through the Model Context Protocol (MCP).

## Infrastructure for AI applications

**[Nubase](https://github.com/OtterMind/Nubase)** is an open-source backend that brings database, file storage, authentication, and memory services together. Use it when an AI-generated application needs to persist data and manage user accounts.

**[ArkMem](https://github.com/OtterMind/ArkMem)** provides a Java-native memory layer for AI agents and applications built on language models. It uses hierarchical storage and semantic retrieval to recall relevant context and user preferences across sessions.
