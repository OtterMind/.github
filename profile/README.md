# OtterMind

我们开发数据库工具和 AI 应用基础设施。想使用 OtterMind 产品，可以直接[打开 OtterMind Studio](https://ottermind.ai/)。如果你是开发者，可以从下面的项目开始。

## 查询和管理数据库

- **[Chat2DB](https://github.com/OtterMind/Chat2DB)** 是本地优先的跨平台数据库客户端。连接 40 多种数据库，在同一个工作区编写 SQL、查看结果和管理数据。
- **[Chat2DB-CLI](https://github.com/OtterMind/Chat2DB-CLI)** 适合在终端或脚本中使用 Chat2DB。它可以管理数据源、执行 SQL，也提供 MCP 接口供 AI 智能体调用。

## 构建 AI 应用

- **[Nubase](https://github.com/OtterMind/Nubase)** 为应用提供数据库、文件存储、身份认证和记忆服务，适合把 AI 生成的代码接入实际后端。
- **[ArkMem](https://github.com/OtterMind/ArkMem)** 为 Java 应用和 AI 智能体提供长期记忆。通过分层存储和语义检索，应用可以在后续对话中找回相关上下文和用户偏好。
